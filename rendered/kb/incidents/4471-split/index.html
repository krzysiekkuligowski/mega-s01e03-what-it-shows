Why these are separate

Shared parser

Every tenant in this incident writes dates day first. The shared parser reads those dates month first, so a valid day-first date can land on the wrong calendar day. This is the parser ticket.

booking-v3 date hint

Three day-first tenants use booking-v3. Its date field displays MM/DD/YYYY, so people enter a month-first value that the tenant-locale form then interprets day first. This is a form-hint ticket, not the shared parser defect.

Method

The export repeats 15 rows, so report IDs were deduplicated before counting. Each unique report was classified from its tenant locale, booking form, and intake channel using causeOf in src/lib/kb/causes.ts.
